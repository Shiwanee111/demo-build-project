# 🚀 Demo Build Project — CI/CD Pipeline

A automated CI/CD pipeline built with Jenkins, Docker, and AWS EC2.

## 🛠️ Tech Stack
- **Python Flask** — Web Application
- **Docker** — Containerization
- **Jenkins** — CI/CD Pipeline
- **AWS EC2** — Cloud Deployment
- **GitHub Webhooks** — Auto Trigger

## 🔄 Pipeline Flow


## 📋 How It Works
1. Developer pushes code to GitHub
2. GitHub webhook triggers Jenkins automatically
3. Jenkins builds Docker image
4. Image pushed to DockerHub
5. App deployed on AWS EC2

App running on: `http://3.111.47.150:3000`
